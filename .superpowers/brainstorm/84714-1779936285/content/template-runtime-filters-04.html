Template Runtime + Filter Scopes

v1 页面只渲染 2 层 filters，但架构先建 3 层 scope，给以后更大产品面留口。

Scope Model
1. Workspace-shared
Architectural scope only for now
以后如果一个 workspace 页面同时挂多个 dashboards，这一层可以统一控制它们。
2. Template-shared
Rendered in v1 control band
一个 filter 只要作用于多个 view / 多个报表块，就应该进模板 control band。
3. View-local
Rendered inside the view
只影响单个 view 的 filter，跟着 view 自己的 card family 和交互走。
