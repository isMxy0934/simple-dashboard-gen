1. Current

当前实现已经有 theme、viewer shell、semantic compiler，但它们还没有收成一套完整的模板 runtime。

Filter

2. Changes

不是重写，而是补 4 个关键层，把分散能力收束成可扩展模板架构。

What We Add
TemplateRuntimeDefinition
shell、control band、zero-view、view family、theme defaults 的单一真相源。
Filter scope contract
`workspace_shared / template_shared / view_local` 三层 scope。
Template-scoped authoring surface
选定模板后，agent 只看到当前模板支持的 skills、families、filters 语境。
View family projection
semantic view kind 先投影到 family，再落成 renderer/style。

3. Target

补完后，新建即进入完整模板世界；agent 和 viewer 都围绕当前模板 runtime 工作。
